CineMatch AI Architecture

How our recommendation engine computes movie vectors

01

Data Preprocessing & Chunking

Aggregates 29+ million ratings from MovieLens using chunked pandas processing to filter down to the top 5,000 most-rated movies.

02

Sparse CSR User-Movie Matrix

Constructs a high-dimensional SciPy Compressed Sparse Row (CSR) matrix mapping user ratings into movie feature vectors.

03

Item-Item Cosine Nearest Neighbors

Trains a scikit-learn NearestNeighbors(metric="cosine", algorithm="brute") model to calculate exact angular similarity between movie vectors.

04

FastAPI Backend & TMDB API Enrichment

Queries vector indices on-the-fly via FastAPI, resolving movie IDs to rich posters, backdrops, ratings, and genre tags via TMDB v3 API.
